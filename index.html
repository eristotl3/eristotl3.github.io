私について

高校ではプログラミング同好会で部長を務め、5人で毎週の勉強会を運営していました。文化祭に向けて Unity で学校をテーマにしたゲームを作り、当日は来場者に実際に遊んでもらいました。

今は、AI がどういう仕組みで動いているのかを学びながら、それを実際に使える製品の形にすることに関心があります。個人開発では、自分が困っていたことを解決するものを作り、きちんと動くところまで持っていくことを大切にしています。エンタープライズの水準で通用する実装力を身につけて、作ったものを積み上げていきたいと考えています。

口座ノート

複数の口座とカードにまたがる支出を、手元だけで追跡・分析する家計簿アプリ

自分の消費が複数の口座とカードに散らばっていて、全体を把握できないことが出発点でした。CSV の取り込みに対応させたので、明細を一件ずつ入力する手間がありません。記録は端末内にだけ残り、Pixel 9a と Mac の同期は同一ネットワーク内で暗号化して直接やり取りします。クラウドには一切送っていません。

Aegis

複数の AI に議論させて、株式の判断材料を提示するデスクトップアプリ

「AI に実際に分析させ、異なる観点から議論させた上で判断材料を出せるのか」を確かめたくて作りました。Alpaca の WebSocket で価格を受け取り、Rust 側で1分足に集約して指標を計算します。その上で4つの役割を与えた AI が意見を出し合い、最後に議長役がまとめます。出力には必ず「この判断が誤りだと分かる条件」と「最も強い反対意見」を含めるようにしました。予測が当たったかどうかも、後から採点しています。作る過程で、TradingView や Alpaca の API の使いどころを知ることができました。

  • Tauri
  • Rust
  • React
  • TypeScript
  • SQLite
